Workflow

Three steps to live payments

01 — Register

Create merchant account

Sign up, receive your API key instantly. Configure webhook endpoints for payment events.

02 — Create payment

Generate checkout link

POST to /create-payment with amount and callback URL. Share the hosted link with your customer.

03 — Settle

On-chain confirmation

Customer sends ETH to a unique address. After 3 block confirmations, we fire your webhook with a signed payload.

create-payment.sh 
curl -X POST https://gaxtron.vercel.app/create-payment \
  -H "X-API-Key: gx_live_..." \
  -H "Content-Type: application/json" \
  -d '{"amount": "0.01", "callback_url": "https://your.app/webhook"}'

# Response
